# AsaPet (KanadePet)

一款基于 **PySide6** 与 **live2d-py** 构建的高自由度 Windows 桌面陪伴宠物。

支持 **Live2D 动态模型与透明 PNG 立绘** 双形态自由切换，深度集成了 **原生鼠标透明穿透（高分屏 DPI 自适应）**、**真实重力抛掷物理**、**本地长短期记忆流** 以及 **桌面应用快速唤起助理**。

---

## ✨ 核心特性

* **双渲染形态无缝切换**
  * **Live2D 模式**：基于 `live2d-py` 与 OpenGL 渲染，支持视线跟随、面部呼吸眨眼、情绪动作分桶映射与 AI 语义选动作；
  * **图片模式**：超轻量运行，内置弹性挤压、回弹、跳跃与左右抖动动画。
* **高分屏 DPI 级透明穿透**
  * 告别大面积透明窗体误触。结合 Win32 `WS_EX_TRANSPARENT` 与 OpenGL Framebuffer 物理像素级 Alpha 采样，鼠标仅在触碰到角色实质像素时捕获交互，透明空白区域 100% 实时穿透至底层工作软件；完美兼容 125%、150%、200% 等 Windows 缩放比例。
* **桌面助手与快捷启动器（专为隐藏桌面图标设计）**
  * **自然语言唤起**：双击小奏说一句*“我想听歌”*、*“帮我开网易云”*、*“打开Steam”*、*“写代码了”*，小奏会在轻柔回应的同时自动在后台秒开软件；
  * **本地快速应用抽屉**：右键呼出「应用抽屉」，0.02 秒遍历扫描桌面与开始菜单中的所有快捷方式，支持即时模糊搜索与 Enter 秒开，桌面再干净也不怕找不到软件。
* **纯净直连的本地记忆架构**
  * **直连任意 LLM 接口**：原生支持 OpenAI 兼容格式（DeepSeek / Kimi / 智谱 / SiliconFlow / 本地 Ollama 等），无需在后台挂载任何第三方复杂服务；
  * **短期上下文持久化**：即使重启程序也能延续上一次的话题聊天下文；
  * **长期生活事实沉淀**：后台无感异步从闲聊中提取你的偏好、习惯与日常事实，自然融入人设 Prompt，越相伴越懂你；
  * **可视化记忆管理**：右键可随时查看、修正、增删长期记忆或清空历史。
* **惯性与重力掉落物理**
  * 开启物理后，支持鼠标抓起角色在桌面甩动抛掷，具有重力加速度、地面反弹与空气阻尼减速。

## 🚀 快速上手

### 方案 A：直接运行已编译版本（推荐）

1. 从 [Releases 页面](https://github.com/Asatsuki0227/AsaPet/releases) 下载最新版的压缩包 `AsaPet-vX.X.X-Windows-x64.zip`；
2. 解压到本地任意非中文或常用英文目录；
3. 双击 `AsaPet.exe` 即可运行。

### 方案 B：从源码运行

#### 环境要求
* Windows 10 / 11 64 位
* Python 3.10 ~ 3.14

```bash
# 1. 克隆代码库
git clone https://github.com/Asatsuki0227/AsaPet.git
cd AsaPet

# 2. 安装基础依赖
pip install PySide6 live2d-py

# 3. 启动程序
python desktop_pet.py
```

## ⚙️ 功能配置指南

### 1. 配置大模型接口
1. 鼠标右键桌宠，点击 **「模型：（未配置）」**；
2. 填写 **Base URL**（如 `https://api.deepseek.com/v1`）；
3. 填写 **API Key**；
4. 点击 **「获取」** 自动拉取服务商支持的模型列表，或手动输入模型 ID（如 `deepseek-chat`）；
5. 点击确定即可。

### 2. 人设与性格定制
* 右键桌宠 → **「编辑人设…」**；
* 直接粘贴角色完整的 System Prompt（设定性格、语气口吻、对用户的称呼与世界观背景），保存即时生效。默认预置为《世界计划》中轻声温柔的**宵崎奏（Kanade）**风格。

### 3. 本地记忆管理
* 右键桌宠 → **「记忆管理…」**：
  * **长期事实记忆**：查看桌宠在日常闲聊中为你记录的个人喜好与近况，支持自由增删改；
  * **对话上下文历史**：按时间轴查看近期交互记录，支持一键清空开启全新话题。

### 4. 隐藏桌面图标后的「快捷启动」
* **语音/文字指令**：双击身体输入*“开下网易云”*、*“打开VSCode”*、*“想玩游戏了”*、*“计算器”*，桌宠自动识别意图并调起对应程序；
* **快捷应用抽屉**：右键桌宠 → 点击 **「应用抽屉（快捷启动）…」**，即时键入拼音或英文筛选（如 `st` 筛选 Steam），按 Enter 立即启动。

## 🎮 交互手势与操作一览

| 操作 | 对应反馈 |
| :--- | :--- |
| **单击身体** | 触发戳一戳反馈 / 动作轮播 / 专属回复台词 |
| **双击身体** | 呼出桌面浮动聊天输入框 |
| **按住左键拖拽** | 抓起角色移动；开启物理时甩动松开可触发**物理抛掷** |
| **鼠标滚轮** | 平滑缩放角色大小（高度范围 120px ~ 800px，防抖合并渲染） |
| **鼠标右键** | 唤起全局功能菜单（应用抽屉、模型设置、人设编辑、记忆库、角色切换等） |

## 📂 自定义角色素材导入

### 使用自己的 Live2D 模型
* 支持 Cubism 3 / 4 / 5（`.model3.json` 规范）；
* 右键菜单 → **「切换角色…」** → 选择「Live2D 模式」→ 浏览选中你的 `.model3.json` 文件；
* 系统会自动解析模型骨骼比例、动作分组及贴图。

### 使用透明 PNG 图片
* 右键菜单 → **「切换角色…」** → 选择「静态图片」→ 选择任意透明背景 PNG 图片即可。

## 📁 模块架构一览

```text
KanadePet/
├── desktop_pet.py           # 桌宠主窗口核心（Win32 穿透、物理模拟、手势分发、托盘）
├── app_launcher.py          # Windows 快捷方式扫描、意图语义分析与启动引擎
├── app_drawer_dialog.py     # 快捷应用抽屉界面（即时模糊检索与原生图标渲染）
├── ai_chat.py               # 直连 AI 通信层、长短期记忆存储与 System Prompt 构造
├── memory_dialog.py         # 记忆库与对话历史可视化管理面板
├── persona_dialog.py        # 人设 System Prompt 编辑器
├── pet_renderer.py          # 渲染层抽象（OpenGL Live2D 驱动器与透明图片驱动器）
├── character_dialog.py      # 角色形态与模型路径切换对话框
├── motion_editor_dialog.py  # Live2D 动作库测试与选择窗口
├── updater.py               # GitHub Release 一键热更新模块（受保护用户数据防覆盖）
├── AsaPet.spec              # PyInstaller 单文件打包规范
└── 1.png                    # 默认角色立绘素材
```

## 🔒 隐私与数据安全

* 你的 **API Key**（`config.json`）、**自定义人设**（`persona.json`）、**长期记忆**（`memory.json`）以及 **聊天记录**（`chat_history.json`）均保存在你本地电脑的程序根目录下；
* 所有配置文件均已配置在 `.gitignore` 中，绝不会随 Git 提交或泄露至任何公网服务器。
